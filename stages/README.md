## Как использовать

1. Идите по порядку, не перескакивая через фундамент.
2. На каждом этапе выполняйте минимум один pet-проект.
3. Ведите [еженедельный лог обучения](../README.md#шаблон-еженедельной-ретроспективы-обучения).
4. Сверяйтесь с [чек-листом на 250+ пунктов](../checklist.md) раз в месяц.
5. Когда этап готов — отметьте его в форке.
